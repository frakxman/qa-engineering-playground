# Software Development Engineer in Test (SDET)

A Software Development Engineer in Test (SDET) combines software development and quality assurance.

Unlike traditional QA Engineers, SDETs are software engineers who specialize in designing, developing, and maintaining testing infrastructure.

They build tools rather than only executing tests.

---

# Responsibilities

An SDET may:

- Design automation frameworks.
- Develop testing libraries.
- Build internal QA tools.
- Create CI/CD pipelines.
- Improve testing infrastructure.
- Review production code.
- Write unit and integration tests.

# QA Engineer vs QA Automation vs SDET

| QA Engineer | QA Automation | SDET |
|--------------|---------------|------|
| Manual testing | Automated testing | Software engineering for testing |
| Test execution | Test scripting | Framework development |
| Functional focus | Automation focus | Engineering focus |
