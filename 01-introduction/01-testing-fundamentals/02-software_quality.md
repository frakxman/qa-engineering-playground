# Software Quality

Software Quality refers to the degree to which a software product satisfies both functional and non-functional requirements while meeting user expectations.

Quality is not only about finding bugs; it also includes performance, security, usability, maintainability, and reliability.

---

# Dimensions of Software Quality

## Functional Quality

The software performs the expected functionality.

Examples:

- Login works correctly.
- Payments are processed.
- Reports are generated.

---

## Non-Functional Quality

The software behaves correctly under different conditions.

Examples:

- Performance
- Scalability
- Accessibility
- Security
- Reliability
- Maintainability

---

# Quality Attributes

| Attribute | Description |
|-----------|-------------|
| Reliability | Works consistently |
| Performance | Responds efficiently |
| Security | Protects data |
| Usability | Easy to use |
| Maintainability | Easy to modify |
| Scalability | Handles increasing load |
| Portability | Runs across environments |

---

# Quality vs Testing

Testing is an activity.

Quality is the final outcome.

Testing contributes to quality but cannot create it alone.

Quality is a shared responsibility involving developers, testers, product owners, designers, and stakeholders.

---

# Quality Throughout the SDLC

Quality should be considered during:

- Requirements
- Design
- Development
- Testing
- Deployment
- Maintenance

This approach is known as Shift-Left Testing.

---

# Key Takeaways

- Quality extends beyond bug detection.
- Functional and non-functional requirements are equally important.
- Every team member contributes to software quality.
