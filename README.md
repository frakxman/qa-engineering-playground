# 🧪 Testing Fundamentals

Learn the core principles of Software Testing through structured notes, practical examples, and interactive engineering labs.

This module covers the essential concepts every QA Engineer, QA Automation Engineer, SDET, and Software Engineer should understand before working with automation frameworks such as Cypress, Playwright, Selenium or Postman.

---

# 📚 Learning Objectives

After completing this module you should be able to:

- Understand the purpose of Software Testing.
- Explain the Software Testing Life Cycle (STLC).
- Differentiate errors, defects, bugs and failures.
- Apply the Seven Principles of Testing.
- Identify testing levels and testing types.
- Design effective test cases.
- Report defects correctly.
- Understand QA roles and responsibilities.
- Build a strong foundation before learning test automation.
