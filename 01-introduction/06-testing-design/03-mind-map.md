# Mind Map Testing

Mind Mapping is a visual technique used to organize testing ideas, requirements, risks, and possible test scenarios.

Instead of writing linear documents, testers create diagrams that show relationships between different parts of the application.

---

# Purpose

Improve test coverage by brainstorming possible testing scenarios.

Mind Maps help QA Engineers think creatively and identify missing test cases.

---

# Example

```
User Registration
│
├── UI
│   ├── Labels
│   ├── Buttons
│   └── Validation
│
├── Inputs
│   ├── Name
│   ├── Email
│   └── Password
│
├── Errors
│   ├── Empty fields
│   ├── Invalid email
│   └── Duplicate account
│
└── Success
    ├── Email sent
    └── Dashboard
```

---

# Benefits

- Encourages creativity.
- Improves requirement understanding.
- Identifies hidden scenarios.
- Organizes ideas visually.
- Useful during exploratory testing.

---

# Common Applications

- Requirement analysis
- Test planning
- Exploratory Testing
- Risk analysis
- Feature decomposition

---

# Popular Tools

- XMind
- MindMeister
- Miro
- Draw.io
- FreeMind

---

# Best Practices

- Start from the main feature.
- Divide into logical branches.
- Expand edge cases.
- Include risks.
- Review with the development team.

---

# Mind Maps vs Test Cases

| Mind Map | Test Case |
|-----------|-----------|
| Brainstorming | Execution |
| Visual | Structured |
| Flexible | Detailed |
| Planning | Validation |

---

# Key Takeaways

- Mind Maps improve test design.
- They encourage creative thinking.
- They help discover missing scenarios before execution.
